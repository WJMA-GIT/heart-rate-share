共享心率 · Windows 版（单文件）

怎么用
  1) 把 heartrate-*-windows-x64.exe 放到任意目录（中文/空格路径都行），双击。
  2) 首次启动会静默释放运行文件到 %LOCALAPPDATA%\heartrate\app\<版本>\，约 1-3 秒；
     之后启动命中缓存，1 秒内出窗口。不会弹解压窗口，也不用找别的文件。
  3) 不需要管理员权限、不写注册表、不建开始菜单。

Windows 可能会提示
  · SmartScreen「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
    （新程序没有下载量信誉，属正常提示；程序未做代码签名。）
  · 防火墙询问 → 允许"专用网络"，否则局域网投射收不到手机广播。

用法
  · 两路数据：蓝牙心率带直连（优先）/ 手机局域网投射（手机与电脑同一 Wi-Fi）。
  · 连接页：扫描蓝牙（心率带被手机连着时 PC 扫不到，先在手机上断开）；
    或从列表里点手机；也可手动填 IP:端口。
  · 房间页：每个人的卡片=头像+心率+迷你折线（与手机悬浮窗同一画法）。
  · 设置页：背景透明开关、日志目录（可一键打开）、版本。

排错
  · 日志：%LOCALAPPDATA%\heartrate\logs\startup.log（崩溃另有 crash.log），
    单文件上限 2 MB，保留 3 份。
  · 起不来时可以加参数：--safe-mode（普通窗口、不初始化蓝牙）或 --opaque（只关透明）。
  · 卸载：删掉 %LOCALAPPDATA%\heartrate 整个目录即可（不留注册表项）。
