共享心率 · Windows 版（免安装）
=================================

怎么跑
------
1. 把整个文件夹解压到任意目录（不要在压缩包里直接双击）。
2. 双击 heartrate.exe。
3. 首次运行 Windows 会弹「Windows 已保护你的电脑」（SmartScreen）：
   点「更多信息」→「仍要运行」。这是因为本程序没有买代码签名证书，不是病毒。
4. 首次联网时 Windows 防火墙会询问是否允许访问网络：
   请勾选「专用网络」并允许，否则局域网里找不到手机。

两条数据通路（界面上会显示当前走哪条）
------------------------------------
A. 蓝牙直连（优先）：电脑有蓝牙 + 心率带在附近 → 点「扫描心率带」→ 选中设备 → 连接。
   需要系统蓝牙已开启；扫不到就先确认心率带没被手机占用。
B. 局域网投射：手机与电脑连同一个 Wi-Fi → 手机上设置里「投射到局域网」保持开启
   （默认开）→ 电脑这边会自动列出手机，点「连接」即可。不需要输入任何房间码。
   连不上时依次检查：同一 Wi-Fi、手机投射开着、防火墙允许"专用网络"、路由器没开 AP 隔离；
   仍不行就在输入框里填「手机IP:端口」（手机设置页会显示端口 8770）。

操作
----
· 按住窗口顶部那条可以拖动整个窗口；
· 右上角第一个按钮切换「背景全透明 / 深色底」；
· 第二个按钮打开连接设置（选设备、扫描心率带、手动 IP）；
· 窗口始终置顶、不占任务栏；背景全透明时，空白处的鼠标点击会穿透到下面的窗口。

数据与隐私
----------
· 局域网投射只监听内网，公网连不上；关掉手机上的开关就会停止监听与广播。
· 同网段的人如果主动连你的手机端口，能看到房间内的心率与昵称（用户已知悉并接受）。
· 本程序不上传任何数据到第三方；检查更新只读 GitHub Release。
