共享心率 · Windows 版（单文件 exe）
===================================

怎么跑
------
1. 把 heartrate-<版本>-windows-x64.exe 放到任意目录（**就这一个文件**，不需要解压、
   不需要 DLL，也不要放进压缩包里运行）。
2. 双击它。首次会自解压到：%LOCALAPPDATA%\heartrate\app\<版本>\，然后自动启动。
   之后每次双击都复用这份解压结果（OverwriteMode=2，已存在的文件跳过）。
3. Windows SmartScreen 提示「已保护你的电脑」：点「更多信息」→「仍要运行」。
   若文件是从网上下载的，也可以右键 → 属性 → 勾选「解除锁定」→ 确定。
4. 首次联网时防火墙询问：勾选「专用网络」并允许，否则局域网找不到手机。

卸载
----
没有安装程序、不写注册表、不要管理员权限。
删除这两处就是干净卸载：
  %LOCALAPPDATA%\heartrate\app\
  %LOCALAPPDATA%\heartrate\logs\

两条数据通路（标题栏会显示当前走哪条）
------------------------------------
A. 蓝牙直连（优先）：点「扫描心率带」→ 选中心率带 → 连接（需要系统蓝牙已开）。
B. 局域网投射：手机与电脑同一 Wi-Fi，手机设置里「投射到局域网」保持开启（默认开）
   → 电脑自动列出手机 → 点「连接」。不需要输入任何房间码。
   连不上依次检查：同一 Wi-Fi、手机投射开着、防火墙允许"专用网络"、路由器没开 AP 隔离；
   仍不行就在输入框里填「手机IP:端口」（手机设置页显示端口 8770）。

操作
----
· 按住窗口顶部那条拖动整个窗口；
· 右上角第一个按钮：背景全透明 / 深色底；
· 第二个按钮：连接设置（选设备、扫描心率带、手动 IP）；
· 窗口置顶、不占任务栏；背景全透明时空白处的点击会穿透到下面窗口。

出问题时
--------
日志（就一个文件，直接发回即可）：
  %LOCALAPPDATA%\heartrate\logs\startup.log
崩溃时同目录还有 crash.log；程序也会弹窗提示日志位置。
如果窗口透明在你的机器上表现异常，可以设环境变量 HEARTRATE_OPAQUE=1 启动
（关掉分层窗口，恢复不透明，功能不受影响）。

数据与隐私
----------
· 局域网投射只监听内网，公网连不上；关掉手机上的开关就停止监听与广播。
· 同网段的人主动连手机端口能看到房间内的心率与昵称（你已知悉并接受）。
· 不上传任何数据到第三方；检查更新只读 GitHub Release。
